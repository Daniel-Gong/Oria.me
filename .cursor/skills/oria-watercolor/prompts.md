## Composition beats (swap into skeleton)

| Beat | Phrase |
|------|--------|
| Edge frame | Color clusters along edges; light open center for type |
| Almost meeting | Two fields that nearly touch, soft gap in the middle |
| Centered calm | Overlapping washes that feel balanced and centered |
| Soft diagonal | Gentle diagonal drift of pigment, still airy |
| Low horizon | Heavier wash along the bottom third only |

## Regeneration notes

- Same prompt + `high` quality can still vary; if one wash is too dark in the center, add: `Keep the center light and open for overlaid typography.`
- If too saturated: `Muted, desaturated pigments; translucent layers only.`
- If too figurative: restate `no objects, no landscapes, no figures — abstract pigment only.`
