The app

What you can do in Oria

Four rooms of the same guide. Start on Free, then open more room with Premium.

01 / Chat

Talk with a coach that already has context

Ask about the week, the pattern you cannot name, or the next move. Oria answers from the life you choose to share, not from a blank thread.

Free includes 20 messages a day. Premium is unlimited.

02 / Memories

Keep what you want remembered

Save moments, notes, and turning points so the model can stay with you. Memory is how Oria becomes a guide instead of a one-off chat.

Free holds 20 saved memories. Premium has no ceiling.

03 / Coaching plans

Turn a goal into a plan you can return to

Build a path you can check against real days, not a list that dies in a notes app. Plans stay next to the chat and the memory that shaped them.

Free includes 3 plans for the life of the account. Premium is unlimited.

04 / Advanced insights

See the shape underneath the week

Premium adds four deeper reads on the data you share: Hidden Patterns, Future Simulation, Anomalies, and Work-Life Balance.

Included with Premium. See plans and limits.
